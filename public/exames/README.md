# Pasta de exames

Coloca aqui os PDFs reais dos exames, com o mesmo nome de ficheiro que está
em `src/data/examesData.js` (campo `ficheiro`). Assim que o ficheiro existir
aqui, o botão "Descarregar" na página `/dashboard/exames` funciona de
imediato — não é preciso mudar nenhum código.

Exemplo: `matematica-12-2024.pdf` corresponde à entrada com
`id: "mat-12-2024"` em `examesData.js`.
